Como usar esta demonstração

Cada aba usa formulários HTML comuns. O navegador envia um POST, o Flask executa o mesmo caso de uso da API e redireciona de volta para a lista.

1. Cadastre um livro Informe título, autor, ISBN e quantos exemplares a biblioteca possui.
2. Cadastre um usuário Nome e e-mail. O e-mail é único no banco.
3. Registre um empréstimo Escolha um livro com exemplar disponível e um usuário sem atraso.
4. Devolva o livro A devolução libera o exemplar na hora e mantém o histórico.
